# Тема

Это тема по умолчанию в репозитории ядра — образец для тем клиентов. Её меняют вместе с ядром:
новый блок каталога, новый вид страницы или поле контракта `ThemeModule` требуют вида и здесь.

В репозитории клиента этот файл заменяется шаблоном [`docs/client/THEME-CLAUDE.md`](../../docs/client/THEME-CLAUDE.md)
(см. [`docs/CLIENT.md`](../../docs/CLIENT.md)). Корневой `CLAUDE.md` подключает его, поэтому правила клиента
действуют с начала каждой сессии.
