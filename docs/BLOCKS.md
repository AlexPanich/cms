# Каталог блоков

<!-- Файл создаёт `pnpm blocks:catalog` из описаний блоков (src/lib/blocks/catalog.ts, src/theme/blocks/) и настроек сайта (src/lib/site-settings.ts, src/theme/settings.ts). Руками не правится. -->

Страница сайта — вертикальная стопка блоков между общими шапкой и подвалом. Здесь перечислены блоки, которые есть в этой установке, их поля и ограничения. Как блоки выглядят в теме — живой каталог `/_blocks` (нужен вход в админку). Правила для макета — [DESIGN-GUIDE.md](DESIGN-GUIDE.md).

Необязательное поле может быть пустым: у блока должно быть оформление и без него. Длина текста — любая до указанного предела.

## Блоки

- Текст (`text`) — Форматированный текст: заголовки, списки, ссылки, картинки, галереи
- Первый экран (`hero`) — Крупный заголовок с подзаголовком, кнопкой и картинкой — начало главной или лендинга
- Карточки (`features`) — Преимущества, услуги или шаги: карточки с иконкой или картинкой, заголовком и текстом
- Картинка и текст (`media-text`) — Картинка рядом с текстом: о компании, услуга, рассказ
- Галерея (`gallery`) — Картинки из раздела «Галереи»
- Призыв к действию (`cta`) — Короткий текст и кнопка: записаться, позвонить, оставить заявку
- Вопросы и ответы (`faq`) — Список вопросов, ответ раскрывается по нажатию
- Последние статьи (`articles`) — Свежие опубликованные статьи и ссылка на все статьи
- Документы (`documents`) — Список файлов для скачивания из раздела «Документы»
- Контакты (`contacts`) — Телефон, почта, адрес, часы работы и соцсети из раздела «Настройки сайта» — для страницы контактов

## Текст (`text`)

Форматированный текст: заголовки, списки, ссылки, картинки, галереи

Оформление: по умолчанию.

| Поле              | Вид                   | Обязательное | Ограничения |
| ----------------- | --------------------- | ------------ | ----------- |
| Текст (`content`) | форматированный текст | да           |             |

## Первый экран (`hero`)

Крупный заголовок с подзаголовком, кнопкой и картинкой — начало главной или лендинга

Оформление: по умолчанию.

| Поле                      | Вид      | Обязательное | Ограничения                                     |
| ------------------------- | -------- | ------------ | ----------------------------------------------- |
| Заголовок (`title`)       | строка   | да           | до 120 символов; одной строкой                  |
| Подзаголовок (`subtitle`) | строка   | нет          | до 300 символов; можно в несколько строк        |
| Кнопка (`button`)         | ссылка   | нет          | страница сайта или адрес, подпись необязательна |
| Картинка (`image`)        | картинка | нет          | кадрируется в 16:9                              |

## Карточки (`features`)

Преимущества, услуги или шаги: карточки с иконкой или картинкой, заголовком и текстом

Оформление: по умолчанию.

| Поле                          | Вид      | Обязательное | Ограничения                                                                                                           |
| ----------------------------- | -------- | ------------ | --------------------------------------------------------------------------------------------------------------------- |
| Заголовок (`title`)           | строка   | нет          | до 120 символов; одной строкой                                                                                        |
| Вступление (`intro`)          | строка   | нет          | до 300 символов; можно в несколько строк                                                                              |
| Карточки (`items`)            | список   | да           | от 1 до 12; элемент — «Карточка»                                                                                      |
| ↳ Иконка (`items[].icon`)     | выбор    | нет          | Без иконки (по умолчанию), Галочка, Звезда, Сердце, Щит, Часы, Доставка, Телефон, Почта, Место, Люди, Награда, Молния |
| ↳ Картинка (`items[].image`)  | картинка | нет          | кадрируется в 4:3. Вместо иконки                                                                                      |
| ↳ Заголовок (`items[].title`) | строка   | да           | до 80 символов; одной строкой                                                                                         |
| ↳ Текст (`items[].text`)      | строка   | нет          | до 300 символов; можно в несколько строк                                                                              |
| ↳ Ссылка (`items[].link`)     | ссылка   | нет          | страница сайта или адрес, подпись необязательна                                                                       |

## Картинка и текст (`media-text`)

Картинка рядом с текстом: о компании, услуга, рассказ

Оформление: по умолчанию, «Картинка справа» (`image-right`).

| Поле                | Вид                   | Обязательное | Ограничения                                     |
| ------------------- | --------------------- | ------------ | ----------------------------------------------- |
| Заголовок (`title`) | строка                | нет          | до 120 символов; одной строкой                  |
| Текст (`content`)   | форматированный текст | да           |                                                 |
| Картинка (`image`)  | картинка              | да           | кадрируется в 4:3                               |
| Кнопка (`button`)   | ссылка                | нет          | страница сайта или адрес, подпись необязательна |

## Галерея (`gallery`)

Картинки из раздела «Галереи»

Оформление: по умолчанию.

| Поле                | Вид     | Обязательное | Ограничения                    |
| ------------------- | ------- | ------------ | ------------------------------ |
| Заголовок (`title`) | строка  | нет          | до 120 символов; одной строкой |
| Галерея (`gallery`) | галерея | да           |                                |

## Призыв к действию (`cta`)

Короткий текст и кнопка: записаться, позвонить, оставить заявку

Оформление: по умолчанию, «На светлом фоне» (`light`).

| Поле                | Вид    | Обязательное | Ограничения                                     |
| ------------------- | ------ | ------------ | ----------------------------------------------- |
| Заголовок (`title`) | строка | да           | до 120 символов; одной строкой                  |
| Текст (`text`)      | строка | нет          | до 300 символов; можно в несколько строк        |
| Кнопка (`button`)   | ссылка | да           | страница сайта или адрес, подпись необязательна |

## Вопросы и ответы (`faq`)

Список вопросов, ответ раскрывается по нажатию

Оформление: по умолчанию.

| Поле                          | Вид                   | Обязательное | Ограничения                    |
| ----------------------------- | --------------------- | ------------ | ------------------------------ |
| Заголовок (`title`)           | строка                | нет          | до 120 символов; одной строкой |
| Вопросы (`items`)             | список                | да           | от 1 до 30; элемент — «Вопрос» |
| ↳ Вопрос (`items[].question`) | строка                | да           | до 200 символов; одной строкой |
| ↳ Ответ (`items[].answer`)    | форматированный текст | да           |                                |

## Последние статьи (`articles`)

Свежие опубликованные статьи и ссылка на все статьи

Оформление: по умолчанию.

| Поле                            | Вид    | Обязательное | Ограничения                    |
| ------------------------------- | ------ | ------------ | ------------------------------ |
| Заголовок (`title`)             | строка | нет          | до 120 символов; одной строкой |
| Сколько статей (`count`)        | выбор  | нет          | 3 (по умолчанию), 6, 9         |
| Ссылка «Все статьи» (`showAll`) | флажок | нет          | по умолчанию включён           |

## Документы (`documents`)

Список файлов для скачивания из раздела «Документы»

Оформление: по умолчанию.

| Поле                            | Вид      | Обязательное | Ограничения                                                     |
| ------------------------------- | -------- | ------------ | --------------------------------------------------------------- |
| Заголовок (`title`)             | строка   | нет          | до 120 символов; одной строкой                                  |
| Документы (`items`)             | список   | да           | от 1 до 50; элемент — «Документ»                                |
| ↳ Документ (`items[].document`) | документ | да           |                                                                 |
| ↳ Название (`items[].title`)    | строка   | нет          | до 200 символов; одной строкой. Если пусто — название документа |

## Контакты (`contacts`)

Телефон, почта, адрес, часы работы и соцсети из раздела «Настройки сайта» — для страницы контактов

Оформление: по умолчанию.

| Поле                               | Вид    | Обязательное | Ограничения                              |
| ---------------------------------- | ------ | ------------ | ---------------------------------------- |
| Заголовок (`title`)                | строка | нет          | до 120 символов; одной строкой           |
| Вступление (`intro`)               | строка | нет          | до 300 символов; можно в несколько строк |
| Показывать соцсети (`showSocials`) | флажок | нет          | по умолчанию включён                     |

## Настройки сайта

Общие для всего сайта: правятся в админке («Настройки сайта») и выводятся в шапке, подвале и блоке «Контакты». Название сайта, описание для поисковиков и текст в подвале — в разделе «Тексты».

| Поле                               | Вид      | Обязательное | Ограничения                                                                                     |
| ---------------------------------- | -------- | ------------ | ----------------------------------------------------------------------------------------------- |
| Логотип (`logo`)                   | картинка | нет          | пропорции любые. Если не задан, в шапке — название сайта                                        |
| Телефон (`phone`)                  | строка   | нет          | до 30 символов; одной строкой; телефон                                                          |
| Почта (`email`)                    | строка   | нет          | до 200 символов; одной строкой; адрес почты                                                     |
| Адрес (`address`)                  | строка   | нет          | до 300 символов; можно в несколько строк                                                        |
| Часы работы (`hours`)              | строка   | нет          | до 300 символов; можно в несколько строк                                                        |
| Соцсети (`socials`)                | список   | нет          | до 12; элемент — «Соцсеть»                                                                      |
| ↳ Соцсеть (`socials[].network`)    | выбор    | нет          | ВКонтакте, Telegram, WhatsApp, MAX, YouTube, Rutube, Дзен, Одноклассники, Другое (по умолчанию) |
| ↳ Адрес страницы (`socials[].url`) | строка   | да           | до 500 символов; одной строкой; адрес http:// или https://                                      |
